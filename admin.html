Background

🎡 Spin wheel

🎮 Games

Built-in types: sniper, hammer, snakes, dart. To add a partner/web game use type url and paste its link — it appears in the app instantly.

✅ Tasks / offers

🎮 Daily Quest — play all games

Shown at the top of the app's Tasks tab: play every game at least once today to claim a bonus.

🏆 Daily Challenge — win or nothing

Shown on the app's Home tab, directly below Spin & Win. Challenge games pay coins only on a win — lose and the player gets nothing. Each challenge game gets a limited number of free attempts per day; extra attempts come from watching a rewarded ad. Tick Challenge game on a game in the Games section above to include it.

🤝 Refer & Earn

Shown on the app's Home tab. Every user gets a share code; a brand-new user who enters someone's code on install day gets the welcome bonus.

💼 Jobs

The manual list below is kept in the config but is not shown in the app (the app's Jobs tab was removed).

💸 Payouts

📜 Redemption Terms & Payout Rules

These lines show on the app's Wallet tab, in the "Redemption Terms & Payout Rules" card. One rule per line — the • bullet is added for you. Wrap words in **double stars** to make them bold, like **100 coins = ₹1**.

📣 Announcement banner

A message strip at the very top of the app's Home tab. Turn it off and Home looks exactly as before.

💎 Sponsors

Sponsor cards rotate on Home, just below the Spin & Win wheel. A card shows when it has a title, text or image. Tapping it opens the link in the browser.

📬 Broadcast message — to all users

A pop-up every user sees once, on opening the app. Current message version: 0. Tick Send as new when saving and the version goes up by 1, so everyone sees the pop-up again — use it whenever you change the message.

🔔 Daily morning notification

The phone itself shows one reminder every morning — no server, no Firebase campaign needed. The app re-arms the next 7 mornings every time it is opened. Write one message per line; they rotate day by day. Use {coins} for the user's balance and {plays} for today's remaining free plays — both are filled in automatically.

📺 Full-screen ads

0 keeps the current behaviour: an ad at every game break. A number (fractions like 0.5 work) quietly skips break ads that come sooner than that after the previous one. Rewarded ads a user taps for extra plays are never skipped.

🔥 Firebase backend (optional)

Server wallet + phone-number login (see backend/SETUP.md). Paste your Firebase web config (Project settings → Your apps → Web) and tick Enabled only after the backend is deployed. While disabled — or with any field blank — the app runs exactly as today with the on-device wallet.
